# Slap the Alarm Quiet

Interactive alarm-clock scene where the alarm is slapped quiet. Sound is synthesized with the Web Audio API, so browsers start it only after a click or tap.

- **Live page:** https://lacynm79.github.io/IXD-107-sequential-interaction-prototype/slap-the-alarm-quiet/
- **Source artifact:** https://claude.ai/artifact/1xHaMC7eBReWGKKsJcENrc (version `1791936308-7cfb`)

## Files

- `index.html`: the complete artifact, transferred unchanged. All images are embedded as data URIs, so there are no separate asset files.

## Running it

No build step, dependencies, or server required. Open `index.html` in a modern browser, or use the live page above.
