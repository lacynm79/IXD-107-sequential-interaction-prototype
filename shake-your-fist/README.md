# Shake Your Fist

Shake the fist side to side to build rage, then punch the ringing alarm clock. Sound is synthesized with the Web Audio API and starts after the first click or tap.

- **Live page:** https://lacynm79.github.io/IXD-107-sequential-interaction-prototype/shake-your-fist/
- **Source artifact:** https://claude.ai/artifact/PAvAxobpcGzZsM2v27mNMQ (version `1791937903-4081`)

## Files

- `index.html`: the complete artifact, transferred unchanged. All images are embedded as data URIs, so there are no separate asset files.

## Running it

No build step, dependencies, or server required. Open `index.html` in a modern browser, or use the live page above.
