# Throw the Clock

Grab the ringing alarm clock and fling it into the wall. Drawn on a canvas; a gentle drop returns it to rest.

- **Live page:** https://lacynm79.github.io/IXD-107-sequential-interaction-prototype/throw-the-clock/

## Running it

No build step, dependencies, or server required. Open `index.html` in a modern browser, or use the live page above.
